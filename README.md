I'm a Senior AI Engineer at AWS in San Francisco. Most of my work lately is around AI agents, coding agent workflows, and figuring out how to verify agent output once it starts hitting real codebases.

## What I've been building

A big chunk of my time goes into [Foxl](https://foxl.ai), a personal AI agent that runs locally on your computer and connects to your phone, along with offline meeting notes and cloud coding agents. Running 15 to 20 coding agents in parallel to build Foxl taught me pretty quickly that generating code is the easy part, and actually knowing if it works is where things get hard. I wrote up what we ran into in [What We Learned Building an AI Software Factory](https://foxl.ai/blog/ai-factory). Some of the pieces around Foxl are open source too, including the [Chrome extension](https://github.com/foxl-ai/browser-extension), [skills library](https://github.com/foxl-ai/skills), and a Rust [Signal CLI](https://github.com/foxl-ai/signal-cli).

A couple of other things I've built recently under [foxl-ai](https://github.com/foxl-ai):

* [Bobcat](https://github.com/foxl-ai/bobcat), a model built for typed decisions that outputs calibrated probabilities over a list of options instead of generating text. Bobcat 1.3 tied for third on the Jev Decision Index, and I also ran it through Pokémon Gold from a new game to see if it could clear all 16 badges ([writeup](https://foxl.ai/blog/bobcat-plays-pokemon-gold)).
* [Kiln](https://github.com/foxl-ai/kiln), an LLM inference engine for AWS Trainium that brings serving techniques from vLLM and SGLang to statically compiled graphs.

On the AWS side, I work on production agent architectures and coding agent platforms like [Coding Agents on AgentCore](https://github.com/aws-samples/sample-amazon-bedrock-agentcore-coding-agents), and I maintain [Amazon Bedrock Client for Mac](https://github.com/aws-samples/amazon-bedrock-client-for-mac), a native Swift app for working with Bedrock models. I've also put together workshops on [Strands](https://catalog.workshops.aws/strands), [AgentCore](https://catalog.workshops.aws/agentcore-deep-dive), and [MCP tooling](https://catalog.workshops.aws/everyday-productivity-accelerators).
